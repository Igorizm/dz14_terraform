# Развертывание инфраструктуры в Cloud.ru с помощью Terraform

Первая часть домашнего задания по работе с Terraform.

## Что реализовано на данный момент
* Настроено подключение к облачному провайдеру **Cloud.ru**.
* Написаны манифесты Terraform для создания двух виртуальных машин:
  * `build-vm` — инстанс для сборки Java-приложения;
  * `prod-vm` — инстанс для запуска приложения.

## В работе
* Настройка автоматической сборки Java-приложения и деплоя на `prod-vm` средствами Terraform.
